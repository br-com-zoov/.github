# Suporte

## Onde perguntar

| Situação | Canal |
|---|---|
| Bug em um repositório | Abra uma **issue** no repositório usando o template *Bug* |
| Pedido de funcionalidade | Abra uma **issue** com o template *Funcionalidade* |
| Dúvida de uso ou integração | Canal `#plataforma-suporte` no Slack |
| Vulnerabilidade de segurança | [`SECURITY.md`](SECURITY.md) — **nunca** em issue pública |
| Incidente em produção | Acione o plantão pelo runbook do serviço |

## Antes de abrir uma issue

- Verifique se já existe issue aberta ou fechada sobre o mesmo assunto.
- Confirme que está na versão mais recente do componente.
- Reúna: versão, ambiente, passos para reproduzir, comportamento esperado e
  observado, e logs relevantes **sem dados sensíveis**.

## Tempo de resposta

Issues são triadas em até 3 dias úteis. Este é um compromisso de triagem, não de
correção — o prazo de correção depende da severidade e é comunicado na própria
issue.

Suporte é oferecido apenas para versões suportadas do componente, conforme
indicado no README de cada repositório.
